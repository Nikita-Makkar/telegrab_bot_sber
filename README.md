# Telegram Bot for Collaborative Code Generation

Telegram-бот для коллективной построчной генерации кода через голосование. Бот генерирует 4 варианта следующей строки кода через LLM, публикует их в Telegram-опросе, собирает результаты голосования и собирает из этих строк файл с кодом.

## Основной функционал

- **Генерация опросов**: 4 опции синтаксически корректной строки кода на основе истории чата (предыдущих опросов); длина каждой ≤ 95 символов
- **Обработка голосов**: обновление результатов по мере прихода poll/poll_answer, закрытие опроса по таймеру или по команде
- **Персистентность**: хранилище истории опросов по чатам; восстановление после рестартов
- **Сборка текущего кода**: выбор победившей опции в каждом завершённом опросе
- **Поддержка множественных LLM провайдеров**: Groq (по умолчанию, бесплатно), OpenAI

## Команды бота

- `/start` (только админ): очистка истории конкретного чата и немедленная отправка первого опроса
- `/code` (всем): показать текущий код чата (как текст, c Markdown-кодблоком)
- `/code_completed` (админ): "доделать" код до компилируемого (через LLM) без добавления новой логики; вернуть текст и файл
- `/sendnow` (админ): отправить следующий опрос немедленно
- `/health` (админ): показать uptime, статус планировщика, наличие активных опросов/время до следующего
- `/logs` (админ): показать последние ~100 строк лога
- `/alllogs` (админ): отправить весь лог файлом

## Установка и настройка

### Требования

- Python 3.10+
- Poetry
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- LLM API Key (один из):
  - **Groq API Key** (рекомендуется, бесплатный) - получить на [console.groq.com](https://console.groq.com/)
  - **OpenAI API Key** - получить на [platform.openai.com](https://platform.openai.com/)

### Установка зависимостей

```bash
# Установить Poetry (если еще не установлен)
curl -sSL https://install.python-poetry.org | python3 -

# Установить зависимости
make dev-install
# или
poetry install
```

### Настройка окружения

Скопируйте `env.example` в `.env` и заполните необходимые значения:

```bash
cp env.example .env
```

Отредактируйте `.env`:

```env
# Telegram Bot Configuration
BOT_TOKEN=your_bot_token_here
ADMIN_USER_IDS=123456789,987654321  # Ваши Telegram user IDs (через запятую)

# LLM Provider Selection (опционально)
# По умолчанию: автоматический выбор (приоритет: Groq -> OpenAI)
# Можно явно указать: groq, openai
LLM_PROVIDER=groq

# Groq API (БЕСПЛАТНЫЙ - используется по умолчанию!)
# Получите ключ на https://console.groq.com/
GROQ_API_KEY=your_groq_api_key_here

# OpenAI Configuration (для переключения на OpenAI)
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-4o-mini  # или gpt-3.5-turbo, gpt-4, etc.

# Bot Settings
POLL_DURATION_SECONDS=300  # 5 минут по умолчанию
MAX_CODE_LINE_LENGTH=95    # Максимальная длина строки кода

# Database
DATABASE_PATH=bot_data.db

# Logging
LOG_LEVEL=INFO
LOG_FILE=bot.log
```

### Выбор LLM провайдера

Бот автоматически выберет доступный провайдер в следующем порядке:

1. **Groq** (если указан `GROQ_API_KEY`) - **рекомендуется для бесплатного использования**
2. **OpenAI** (если указан `OPENAI_API_KEY`)

Вы можете явно указать провайдера через переменную `LLM_PROVIDER=groq` (или `openai`).

### Получение Telegram User ID

Чтобы узнать свой User ID:

1. Напишите боту [@userinfobot](https://t.me/userinfobot)
2. Скопируйте ваш ID и добавьте в `ADMIN_USER_IDS`

## Как это работает

1. Администратор отправляет `/start` в чат - история очищается и создается первый опрос
2. LLM генерирует 4 варианта следующей строки кода на основе предыдущих выбранных строк
3. Бот создает Telegram-опрос с этими 4 вариантами
4. Пользователи голосуют за понравившийся вариант
5. По истечении времени опрос закрывается, выбирается вариант с наибольшим количеством голосов
6. Автоматически создается следующий опрос для следующей строки
7. Процесс повторяется, формируя код построчно

## База данных

Бот использует SQLite для хранения (для простаты выбрал ее):

- История опросов по чатам
- Результаты голосований
- Активные опросы

База данных автоматически создается при первом запуске. Путь к базе данных настраивается через `DATABASE_PATH` в `.env`.

## Логирование

Логи сохраняются в файл, указанный в `LOG_FILE` (по умолчанию `bot.log`). Используется ротация логов (максимум 10MB на файл, до 5 файлов).

Уровень логирования настраивается через `LOG_LEVEL` (DEBUG, INFO, WARNING, ERROR, CRITICAL).

## Тестирование

Проект включает комплексные тесты для всех компонентов:

- **Тесты базы данных** (`test_database.py`) - сохранение опросов, голосование, очистка истории
- **Тесты LLM сервиса** (`test_llm_service.py`) - генерация опций, завершение кода, обработка ошибок
- **Тесты управления опросами** (`test_poll_manager.py`) - создание, закрытие, статус опросов
- **Тесты обработчиков команд** (`test_handlers.py`) - все команды бота, проверка прав доступа
- **Тесты утилит** (`test_utils.py`) - построение кода, экранирование HTML, форматирование ошибок

Запуск тестов:

```bash
# Все тесты
make test

# С покрытием кода
make test-cov

# Конкретный тест
poetry run pytest tests/test_database.py -v
```

## Безопасность

- **Никогда не коммитьте `.env` файл** в репозиторий (уже добавлен в `.gitignore`)
- Храните токены и ключи API в безопасном месте
- Ограничьте доступ администраторов только доверенным пользователям
- Используйте переменные окружения для конфиденциальных данных
- Регулярно обновляйте зависимости: `poetry update`

## Ограничения

- Опросы автоматически закрываются через `POLL_DURATION_SECONDS` секунд
- Каждая строка кода ограничена `MAX_CODE_LINE_LENGTH` символами
- Только администраторы могут выполнять некоторые команды

## Разработка

### Качество кода

Проект следует лучшим практикам разработки:

- **Типизация**: полная аннотация типов (type hints) во всех модулях
- **DRY принцип**: общие функции вынесены в `bot/utils.py`
- **PEP8**: код соответствует стандартам Python (длина строк 100 символов)
- **Тестирование**: высокое покрытие тестами, включая edge cases

### Добавление новых команд

1. Добавьте обработчик в `bot/handlers.py`
2. Роутер уже зарегистрирован в `bot/main.py`
3. Добавьте тесты в `tests/test_handlers.py`

### Изменение логики генерации кода

Редактируйте промпты в `bot/llm_service_unified.py` в методах:

- `generate_code_options()` - генерация 4 вариантов следующей строки
- `complete_code()` - завершение кода до компилируемого состояния

## Troubleshooting

### Бот не отвечает

- Проверьте `BOT_TOKEN` в `.env`
- Убедитесь, что бот запущен: `make run`
- Проверьте логи: `tail -f bot.log`

### Ошибки с LLM API

**Groq API:**

- Проверьте `GROQ_API_KEY` в `.env`
- Получите бесплатный ключ на [console.groq.com](https://console.groq.com/)

**OpenAI API:**

- Проверьте `OPENAI_API_KEY` в `.env`
- Убедитесь, что у вас есть доступ к выбранной модели
- Проверьте баланс аккаунта OpenAI

### Проблемы с базой данных

- Убедитесь, что у бота есть права на запись в директорию с базой данных
- При необходимости сбросьте базу: `make db-reset`
